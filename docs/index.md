**«Досмотр»** — трекер сериалов и фильмов для Android. Библиотека тайтлов, отметки серий
по сезонам, статусы, оценки, заметки и статистика просмотренного времени. Метаданные
приходят из собственного бэкенда проекта; всё, чего в нём нет, добавляется вручную.

Библиотека, отметки, оценки и заметки хранятся **только на устройстве** и никуда не
отправляются — подробно и по пунктам это описано в
[политике конфиденциальности]({{ '/privacy/' | relative_url }}).

> **Поддержать автора.** Приложение бесплатное и таким останется; за перевод ничего не
> даётся взамен и никакие функции он не открывает.
> [Способы поддержки]({{ '/support/' | relative_url }})

## Где взять

- [APK с GitHub Releases]({{ site.releases_url }}) — сборка `direct`, без единой строки
  кода Google.
- RuStore и Google Play — готовятся; ссылки появятся здесь.

Сборка из магазина и сборка с Releases — одно и то же приложение с одной подписью:
APK отсюда обновится магазинным без потери библиотеки.

## Что умеет

- **Библиотека** — карточки с постером, прогрессом (`12 / 24`), кнопкой «+1 серия»,
  фильтрами по статусу и типу.
- **Поиск** — тренды недели на пустом запросе, добавление в один тап.
- **Ручное добавление** — работает без сети: название, тип, серии по сезонам строкой
  `12, 10, 8`, длительность, год.
- **Экран тайтла** — сезоны, отметка серии, «весь сезон», «отметить всё до этой серии»,
  статус, оценка, заметки, обновление списка вышедших серий.
- **Статистика** — суммарное время, серии, фильмы, разбивка по статусам.
- **Экспорт и импорт JSON** — резервная копия лежит там, где вы её положили, а не в
  чужом облаке.
