# Store listing — English (draft, not published)

A placeholder for stage 2 of `product/03-roadmap.md`. The app itself is Russian-only —
every string in the UI is a Russian literal — so publishing an English listing before the
app is translated would send English-speaking users to a Russian app. Nothing here goes
into a console until that changes.

It is written down now because the Russian card was written now, and translating it later
from a console field is how the two drift apart.

Lengths are the same as in `listing-ru.md`: 30 characters for the Google Play title, 80
for the short description.

---

## Title

**Google Play** (30 characters max):

```
Dosmotr: TV show tracker
```

**RuStore** (50 characters max):

```
Dosmotr — TV show and movie tracker
```

## Short description (80 characters max)

```
Track the episodes you have watched. No account, no VPN, no ads.
```

## Full description

```
Tick off the episodes you have watched and never lose your place. Everything stays on
your device.

• A library with statuses: watching, planned, on hold, completed, dropped.
• Seasons and episodes: one tap for an episode, two for a whole season, and the card
  tells you which episode is next.
• Movies too — one tick instead of a list of episodes.
• Your own rating and notes on every title. They stay with you.
• Statistics: how much time you have watched, how many episodes and films, what is left.
• Export the library to JSON, and an automatic backup into a folder you choose.
• Dark theme and Material You — the app takes its colour from the system.
• Add a title by hand when the catalogue does not have it.

No account, no sync, no ads. The only thing that leaves the device is a search query and
the artwork and synopses that come back.

This application uses TMDB and the TMDB APIs but is not endorsed, certified, or
otherwise approved by TMDB.
```

The TMDB sentence is the same one, verbatim — it is in English in the Russian listing too,
because that is the form the attribution is required in.
